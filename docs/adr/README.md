# Architecture Decision Records

One file per ratified decision, numbered, never edited after acceptance — supersede with a
new ADR instead. Agents and humans read these before proposing architecture changes; a PR
that contradicts an accepted ADR must supersede it explicitly.

Format per record:

```markdown
# NNNN — Title

- Status: accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context

Why a decision was needed.

## Decision

The call, stated plainly.

## Consequences

What this makes easier, what it makes harder, what it forbids.
```
